키맞춤

악보 사진의 코드를 확인하고, 같은 높이로 부르는 우리 팀의 키 후보를 비교해요. 선택한 키로 코드 악보와 피아노 반주를 만들어요.

1악보 넣기

악보 이미지 올리기

자동 인식은 임시표(#·♭), 분수코드, 반복 번호를 틀릴 수 있어요. 인식 후 원본과 대조하세요.

2제일 낮은 음, 제일 높은 음 누르기

자동 선율 판독은 참고값이에요. 코드만 바꾼 이미지를 다시 올리면 음표·조표는 이전 키일 수 있어요. 낮은 음을 자동 제외하거나 옥타브를 바꾸지 않아요.

4코드 검토 · 바뀐 코드 악보

기본은 원본 보존 + 바뀐 코드표예요. 원본 위 교체는 모든 코드와 지울 영역을 확인한 뒤 켤 수 있어요. 오선 음표·조표는 바뀌지 않아요.

잘 읽음확인해 주세요못 읽음

단순 피아노 코드 반주예요. 코드 위치에서 박자를 추정하므로 원곡 반주·반복 순서와 다를 수 있어요. 템포와 박자를 직접 맞추고 들어보세요. 실험적 멜로디는 음표 판독 검수가 필요해요.

5이어 부르기 (여러 곡)

곡마다 전체 음역을 비교해 연습할 키 후보를 골라요. 음역 적합성을 먼저 보고 곡 사이 키 이동도 비교해요. 곡 이름을 누르면 4번에 그 곡이 떠요.

곡 여러 장 올리기
우리 팀 음역

세 사람이 같은 실제 높이로 부르는 기준이에요. 기존 값은 과거 이미지에서 읽은 미검증 최대 범위입니다. 각자의 편한 최저·최고음을 다시 맞추고 확인해 주세요. 특히 미소의 B♭4 / B♭5를 확인하세요. 성별로 옥타브를 자동 변경하지 않아요.
