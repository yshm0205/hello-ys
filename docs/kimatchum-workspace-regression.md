# 키맞춤 작업실 복원 회귀 목록

기준: 기존 `public/kimatchum-engine/index.html`의 1~5 단계와 접힌 팀 설정. 이전 Render 화면의 흐름도 부모가 확인했다. 새로운 접수 흐름으로 기존 작업을 대체하지 않는다.

| 기존 기능 | 복원 방식 / 검증 |
|---|---|
| 1 악보 넣기, 곡명, 코드 키·음표 키 | 기존 입력과 이미지 처리 그대로. 실제 PNG 업로드·미리보기 확인 |
| 브라우저 OCR / 선택적 서버 AI | 기존 엔진·서버 권한 유지. 오프라인 OCR 실패 시 직접 입력 안내 확인. 인식 정확도 및 AI 호출은 이번 검증 범위 밖 |
| 2 최저·최고음 오선 클릭, 싱어 음역 막대 | 기존 SVG와 클릭 처리 유지·클릭 검증 |
| 3 12개 키 후보·코드 변환 | 12개 키 표시·선택 확인. 입력 공통 음역이 좁으면 키 변경만으로 맞출 수 없다는 경고 확인. 파트·옥타브 자동 분담 없음 |
| 4 원래/바꾼 키 보기 | 토글 상태 확인. 오선 음표·조표는 원본이라는 설명 유지 |
| 코드 수정·확인·추가·삭제·영역 보호 | 기존 핸들러 보존. 같은 줄의 다음 영역과 명시적 병합 추가. 이름은 사용자가 직접 수정하며 병합 시 검토·영역 안전 확인은 초기화. C#/E# 수정·확인 및 미검토 영역 덮어쓰기 거절 확인 |
| 형광펜·구간·가사 두 줄 | 기존 도구 보존. 모드 전환·색 선택·구간 추가 모드·가사 옵션 클릭 확인 |
| 반주·일시정지·정지·처음부터·템포·박자 | 기존 WebAudio/Transport 보존. 재생 상태 전환 확인. 원곡 리듬 정확도 보증 없음 |
| 실험적 멜로디 | 기존 실험 표시 및 기본 꺼짐 유지. 실제 음높이·리듬·가창 적합성은 미검증 |
| A4 구성·PNG 저장 | 메모 입력·A4 생성·다운로드 링크 확인. 코드만 전조하고 음표는 원본이라는 출력 설명 유지 |
| 5 여러 곡 이어 부르기 | 복수 업로드·곡 선택·키 변경·전조 옵션·순서 변경·삭제 확인. 실제 곡 연결 청취 정확도는 별도 검증 필요 |
| 우리 팀 음역 | 기존 접힌 설정 유지. 3명 표시·범위 변경·추가·삭제 확인 |
| 독립 브랜딩 | 종이/초록 디자인 유지. 기존 작업실 중복 헤더 제거. 외부 상담창 없음 |
| 접수·이메일·로그인 | 별도 보조 탭. request 링크는 검수 탭을 바로 연다. 기존 본인 제한·동의·확인·메일 서버 계약은 변경 없음 |
| 탭 전환 | 작업 상태 유지, 숨겨진 화면의 오디오 정지. 새로고침 시 초기화 명시 |

로컬 증거: `trial-tests/restoration-browser.cjs`, `restoration-browser-result.json`, `branding-browser.cjs`, `branding-browser-result.json`, `build.log`, `original-engine-*.png`, `restored-workspace-*.png`.

Chrome 1280px/390px에서 production 빌드 사용. 외부 네트워크 차단, 인증·메일 API는 로컬 모의 응답. 실제 이메일·AI 요청 없음. 기존 27개 서버/인증/검수 테스트 통과. 운영 배포와 실제 OCR·멜로디 정확도 승인은 별도이며 이 목록은 해당 승인을 의미하지 않는다.

## 실제 후회 원본 추가 회귀

`no-regret-A.png` 원본 773×951 RGBA를 실제 브라우저 OCR로 읽었다. 이 추가 실행만 Tesseract 공개 스크립트·모델 다운로드를 허용했다. 이미지 전송 API·AI·메일은 호출하지 않았다. 54개가 나왔지만 자동 정확도는 통과하지 않았다. 4·12·25·33번 C#m/E, 27번 A/C#, 45번 B/D#, 47번 C#/E# 오독을 메인 편집 UI로 고친 후 수동 전사 기준 54개와 일치했다.

이번 원본 OCR에서는 분리된 55개와 Fbm이 나오지 않아, 이 두 오류 형태는 테스트에서 명시적으로 재현했다. 기존 47번 영역 삭제 → C#와 E# 영역을 직접 추가 → 55개 → 다음 영역 병합 → C#/E# 직접 입력 → 54개로 복구했다. Fbm 입력 후 F#m 수정도 확인했다. 병합 후 영역 안전 확인 해제, 다른 오선으로의 병합 거절도 통과했다. 정답 배열은 테스트에만 있으며 서비스 코드에 곡별 정답을 넣지 않았다.

증거: `trial-tests/original-score-main.cjs`, `original-score-ocr.json`, `original-score-correction-result.json`, `original-score-main-corrected.png`. 이 증거는 직접 교정 가능성을 검증하며 자동 음악 인식·가창 적합성 검증 완료를 뜻하지 않는다.
